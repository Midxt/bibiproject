# Campus Connect

A responsive campus events app built with Next.js App Router, React Context, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to explore the event directory.

## Included

- Event data in `data.js`
- Search by title, category filters, and date sorting
- Dynamic event pages at `/events/[id]`
- Saved events persisted in local storage through React Context
- Countdown timer and responsive event card grid
